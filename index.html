About Me

Hi, I'm Priyanka Mhaske — a Frontend Developer based in Nashik, India. I recently graduated with a BCA and love turning ideas into real, working web applications. I work with HTML, CSS, JavaScript, PHP, and MySQL, and I've been exploring AI integration using Python and LLM APIs.

I enjoy building things end-to-end — from designing the interface to deploying the final product. Some of my projects include a multi-user e-commerce platform for farming equipment and an AI-powered quiz generator. I'm currently learning React to build more dynamic, modern interfaces, and I'm always excited to pick up new tools and keep growing as a developer.

I'm open to entry-level Frontend Developer and AI-adjacent roles — feel free to check out my work or get in touch!
